# 必需

pyguitarpro>=0.11
pretty_midi>=0.2.11
numpy>=2.0               # 3.13 只有 numpy>=2 的预编译包；1.x 要现场编译源码，会失败
soundfile>=0.12          # 读写音频文件（L2 分离要用）
setuptools<81            # basic_pitch 依赖一个老接口 pkg_resources，81 版起被删掉，不钉住就 import 失败

# ---------------------------------------------------------------------------
# 听音频 → 音符（L3）
# ---------------------------------------------------------------------------
# Spotify 出的开源转写模型，会连带装 TensorFlow（约 1GB）。
# 整曲混音准确率只有 F1≈0.43（"一半对一半错"级别），单乐器干净录音才好用，
# 所以要和下面的 demucs 配合：先分离、再转写。
basic_pitch

# ---------------------------------------------------------------------------
# 把一首歌拆成人声/贝斯/其它/鼓（L2）
# ---------------------------------------------------------------------------
# Meta 出的开源分离模型，会连带装 PyTorch（约 800MB）+ 模型权重。
# 注意：它的官方仓库从 2023-11 起就没人维护了（"上游归档"= 原作者那边关门了，
# 以后不会再修 bug）。今天还能用，替代路线见文件末尾的 msst。
demucs

# ---------------------------------------------------------------------------
# 打拍子（L4）—— 已经接进代码，不是可选装饰
# ---------------------------------------------------------------------------
# 从音频里找"每拍在哪一小节第一拍在哪"。之前是我们自己用"音符之间的间隔"倒推，
# 等于拿转写结果去验证转写结果，一首真实歌曲上把速度判成了 94 BPM，
# 而音频自己的周期性证据指向 111 BPM。接上它之后修正为 111.1。
# 它的模型权重放在奥地利 JKU 大学自己的服务器上，不在 github，
# 所以连 github 不通的时候也能下载成功。
beat-this

# ---------------------------------------------------------------------------
# 开发/测试
# ---------------------------------------------------------------------------
pytest

# ---------------------------------------------------------------------------
# 下面这些是"外部程序"，不是 pip 能装的东西。缺了都能跑，只是质量降级，
# 而且命令行会明确告诉你这次用的是哪一个。
#
#   brew install --cask musescore
#       → 出版级 PDF/矢量图。4.7.5 版有两个坑：手册里的 -s 参数根本不存在
#         （传了就直接不干活）；退出码不可信（它收尾时会假装崩溃，
#         所以只能看"文件有没有真的生成"来判断成败）。
#   brew install fluid-synth
#       → 真实吉他音色的试听音频。必须加 -g 1.0：它默认主音量是 0.1，
#         不加就会比任何正常播放器小五倍。
#   音色库（.sf2 / .sf3）
#       → brew 不提供，这台机器上原本一个都没有。现在退而用 MuseScore
#         自带的 MS Basic.sf3；想换成自己的：export RESONOTE_SOUNDFONT=路径
#   LilyPond 2.26
#       → 满页和弦框那种图表谱。注意 brew 装不上（brew 版本比它的安装包元数据
#         旧，报 unknown install step），要用官网的 darwin-arm64 压缩包自己装。
# ---------------------------------------------------------------------------
