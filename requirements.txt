# 听音频 → 音符（L3）
# ---------------------------------------------------------------------------
# Spotify 的开源转写模型。整曲混音准确率只有 F1≈0.43（"一半对一半错"级别），
# 单乐器干净录音才好用，所以要和下面的 demucs 配合：先分离、再转写。
#
# 它**不进下面的自动安装清单**，因为要用 --no-deps 单装：basic_pitch 把
# TensorFlow 写成硬依赖，而 Mac 那条 TensorFlow 产品线钉的
# tensorflow-macos<2.15.1 从来没出过 Python 3.12 的包 —— 交集为空，装不上。
# 但推理根本不需要 TensorFlow：同一个模型在包里有四份包装
# （TF 1.3MB / onnx 228KB / tflite 200KB / CoreML），transcribe.py 现在
# 明确走 ONNX 那份，所以两端都能用 3.12。2026-10-04 实测：合成旋律 8 音全命中。
#
#   uv pip install --python .venv --no-deps basic-pitch
#
# 它真正需要的东西在下面这些名字里，正常装即可。
onnxruntime>=1.17         # 跑 ONNX 模型（mac 21.5MB / win 14.3MB，都有 3.12 现成包）
librosa>=0.10             # basic_pitch 用它重采样和读音频
scipy                     # librosa 依赖
numba                     # librosa 依赖
resampy<0.4.3             # basic_pitch 钉的；0.4.2 里 import pkg_resources，所以上面 setuptools 要 <81
mir_eval                  # basic_pitch 的 note_creation 会 import 它

# ---------------------------------------------------------------------------
# 把一首歌拆成人声/贝斯/其它/鼓（L2）
# ---------------------------------------------------------------------------

# 注意：它的官方仓库从 2023-11 起就没人维护了（"上游归档"= 原作者那边关门了，
# 以后不会再修 bug）。今天还能用，替代路线见文件末尾的 msst。
demucs

# ---------------------------------------------------------------------------
# 打拍子（L4）—— 已经接进代码，不是可选装饰
# ---------------------------------------------------------------------------
# 从音频里找"每拍在哪一小节第一拍在哪"。之前是我们自己用"音符之间的间隔"倒推，
# 等于拿转写结果去验证转写结果，一首真实歌曲上把速度判成了 94 BPM，
# 而音频自己的周期性证据指向 111 BPM。接上它之后修正为 111.1。
# 它的模型权重放在奥地利 JKU 大学自己的服务器上，不在 github，
# 所以连 github 不通的时候也能下载成功。
beat-this

# 下面这些是"外部程序"，不是 pip 能装的东西。缺了都能跑，只是质量降级，
# 而且命令行会明确告诉你这次用的是哪一个。
#
#   brew install --cask musescore
#       → 出版级 PDF/矢量图。4.7.5 版有两个坑：手册里的 -s 参数根本不存在
#         （传了就直接不干活）；退出码不可信（它收尾时会假装崩溃，
#         所以只能看"文件有没有真的生成"来判断成败）。
#   brew install fluid-synth
#       → 真实吉他音色的试听音频。必须加 -g 1.0：它默认主音量是 0.1，
#         不加就会比任何正常播放器小五倍。
#   音色库（.sf2 / .sf3）
#       → brew 不提供，这台机器上原本一个都没有。现在退而用 MuseScore
#         自带的 MS Basic.sf3；想换成自己的：export RESONOTE_SOUNDFONT=路径
#   LilyPond 2.26
#       → 满页和弦框那种图表谱。注意 brew 装不上（brew 版本比它的安装包元数据
#         旧，报 unknown install step），要用官网的 darwin-arm64 压缩包自己装。
# ---------------------------------------------------------------------------
